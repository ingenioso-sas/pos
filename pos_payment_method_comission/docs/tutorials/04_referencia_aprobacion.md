# Escenario 4: Referencia de Aprobación Obligatoria
**Objetivo:** Mostrar cómo el módulo evita errores exigiendo comprobantes para métodos de crédito.

## 1. Configuración
1. En método de pago (ej. "Crédito Addi"), activa **"Pedir Referencia de Aprobación"**.

## 2. Ejecución
1. En TPV, intenta pagar con Crédito Addi y presiona Validar.
2. Un Popup rojo bloqueará el pago pidiendo la referencia.
3. Ingresa el voucher en la caja de texto y valida de nuevo.
